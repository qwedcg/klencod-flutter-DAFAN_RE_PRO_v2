# DAFAN RE PRO — v2.0

مشروع Android Java أصلي للتحليل الثابت واستخراج محتويات الملفات عبر الهاتف.

## ما الذي تحسّن؟
- لا يتم تحميل الملف كاملاً إلى الذاكرة.
- أحجام الملفات وحساب الإزاحات تستخدم `long`، مع نسخ/قراءة على دفعات 128KB.
- استخراج أقسام ELF/SO الفعلية من جدول الأقسام، مع أسماء مثل `.text` و`.rodata` و`.data`.
- استخراج ZIP/APK/JAR/OBB المتوافقة مع ZIP عبر `ZipInputStream` وبشكل متدفق.
- استخراج سلاسل ASCII إلى ملف نصي.
- فحص تواقيع PNG/JPEG/ZIP المضمّنة وإخراج تقارير بالإزاحات، دون قصّ بيانات مجهولة الطول بشكل مضلل.
- اختيار مصدر الملف ومجلد الإخراج من مدير ملفات أندرويد (SAF).

## حدود مهمة وصريحة
- لا يوجد حد 100MB مفروض من التطبيق، ولا يحمل التطبيق الملف كاملاً في RAM. عملياً يعتمد الحد على مزود الملفات ومساحة التخزين ونظام الملفات ووقت المعالجة.
- بعض مزودي SAF لا يدعمون `FileChannel`/الوصول العشوائي؛ استخراج أقسام ELF يحتاج ملفاً قابلاً للبحث (seekable).
- ELF extended section numbering غير مدعوم في هذا الإصدار.
- ملفات SO لا تُفك عادةً إلى ملفات مستقلة اعتباطياً؛ التطبيق يستخرج أقسام ELF كما هي مخزنة.
- هذا الإصدار لا يفك تشفير Unreal PAK/IoStore، ولا يستخرج UASSET/UEXP من حاوية PAK. ذلك يحتاج محركاً متخصصاً وإصدار الحاوية ومفاتيح التشفير إن كانت محمية.
- لا يوجد حتى الآن Disassembler/Decompiler فعلي مثل Ghidra/Rizin؛ هذا إصدار استخراج وتحليل بنيوي أولي.

## البناء من الهاتف
1. أنشئ مستودع GitHub فارغاً باسم `DAFAN-RE-PRO`.
2. ارفع محتويات هذا المجلد إلى جذر المستودع.
3. افتح Actions وشغّل workflow المسمى **Build DAFAN RE PRO APK**.
4. نزّل artifact باسم `DAFAN-RE-PRO-debug` ثم ثبّت `app-debug.apk`.

يمكن أيضاً فتح المشروع في AndroidIDE أو بيئة Android Gradle متوافقة.

## ملاحظة أمان
استخدم الأداة على ملفات تملكها أو لديك تصريح لتحليلها. لا تنفّذ الملفات المستخرجة.
